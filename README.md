# Eyekea

Eyekea gives IKEA's sustainability and compliance managers an overview of who works in the supply chain and under what conditions. It shows every site on a map of Germany, highlights sites with high risk, and highlights sites where nobody has reported data.

This is a prototype for the TEK830 IKEA capstone at Chalmers, made by team 9. All supplier names and figures are made up.

## Get started

You need Node 24 and pnpm.

```sh
pnpm install
pnpm dev
```

Open http://localhost:5173.

## What is where

| Path | Contents |
| --- | --- |
| `src/routes/` | One file per page. The file name is the URL. |
| `src/routes/_explorer.tsx` | The map and graph on the left, with the view and filter in the URL. |
| `src/routes/_explorer/index.tsx` | The overview panel on the right at `/`. |
| `src/routes/_explorer/sites.$siteId.tsx` | The site panel at `/sites/<id>`. |
| `src/routes/design.tsx` | The design page at `/design`, with every UI component. |
| `src/components/ui/` | Buttons, tabs, pills, status dots, and cards in IKEA's Skapa style. |
| `src/features/` | The map, the graph, and the overview chart. |
| `src/supply-chain/` | The data schema, loading, and risk assessment. |
| `public/data/supply-chain.json` | The mock data. It is generated by `scripts/generate-mock-data.py`. |
| `docs/` | Progress and the data model. |

## New to React or TanStack Router?

- Start with the [TanStack Router tutorial on file-based routing](https://tanstack.com/router/latest/docs/framework/react/routing/file-based-routing).
- Read `src/routes/_explorer/sites.$siteId.tsx` first. It shows a loader, a typed param, and a not-found page in one file.
- Open `/design` to see which components exist before you build a new one.
